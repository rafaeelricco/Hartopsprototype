Durations

Four duration tokens. 100ms is micro-feedback; 200ms is the default for UI transitions; 300/500ms are reserved for sheet transitions.

fast · 100ms
press flash, focus fade
normal · 200ms
standard UI transition
slow · 300ms
sheet close, cross-fade
slower · 500ms
sheet open (bottom-sheet rise)

Easing

Each 1.2s loop — same distance, different curve. ease-in-out is the default for hover, color, and layout shifts.
